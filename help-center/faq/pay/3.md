# 결제 취소는 언제까지 가능한가요?

결제일로부터 **30일 이내**에 가능합니다.\
단, 충전된 크레딧을 **단 1건도 사용하지 않은(사용 이력 0건)** 경우에만 직접 결제 취소가 가능합니다.

***

#### **Q. 크레딧을 1건이라도 썼다면 결제 취소가 안 되나요?**

네, 크레딧을 1건이라도 사용하셨다면 전액 결제 취소는 불가능합니다.\
하지만 남은 크레딧은 이용 기간(30일)이 끝날 때까지 자유롭게 사용하실 수 있어요.\
기간이 종료되면 \[사용 개수 × 정상 단가]를 제외한 나머지 금액을 자동으로 환불해 드립니다.

{% hint style="warning" %}
크레딧을 모두 사용했거나 이용 기간이 이미 지난 상품은 취소나 환불이 불가능합니다.
{% endhint %}

#### **Q. 결제 후 30일이 지나면 남은 크레딧은 어떻게 되나요?**

이용 기간(30일)이 종료되면 별도로 신청하지 않으셔도 자동으로 환불 절차가 진행됩니다.

#### **Q. 바우처도 사용하지 않으면 환불이 되나요?**

아니요, 바우처는 직접 결제하신 상품이 아닌 이벤트나 프로모션으로 제공된 '혜택'이므로\
환불이나 타인 양도가 불가능합니다. 유효기간이 지나면 자동으로 소멸되니 기간 내에 꼭 사용해 주세요.

# \[공지] 오픈 베타 연장 안내

📢 안녕하세요, 리사이즈애드 팀입니다.\
먼저 오픈 베타 서비스(OBT) 기간 동안 보내주신 파트너 여러분의 성원과 소중한 피드백에\
진심으로 감사드립니다.✨

더욱 안정적인 서비스 환경을 제공하고자 **OBT 기간을 2026년 5월 10일까지 연장**합니다.\
기간 연장에 따른 운영 정책 및 혜택을 아래와 같이 안내드립니다.

***

#### 1️⃣ 기존 무상 크레딧 이용 기간 연장 ⏳

당초 3월 31일 만료 예정이었던 기존 무상 크레딧의 사용 기한이\
**2026년 5월 10일까지 자동 연장**되었습니다. 남은 기간 동안 부담 없이 ResizeAd의 기능을 경험해 보세요!



#### 2️⃣ OBT 한정 특별가 제공 (1,500원/1개) 💰

정식 출시 전, 오직 OBT 기간에만 적용되는 파격적인 특별 할인가로 구매하실 수 있습니다.🔥

<a href="https://resizead.kr/billing/plans" class="button primary">혜택가로 크레딧 구매하기</a>

{% hint style="info" %}
정식 오픈 후에는 런칭 단가로 인상될 예정이며, **현재의 1,500원 단가는 OBT 종료 전까지만 구매 가능**합니다.
{% endhint %}



#### 3️⃣ 서비스 품질 개선을 위한 피드백 이벤트 🎁

더 나은 ResizeAd를 위해 여러분의 소중한 의견을 기다립니다.\
사용성 개선, 배너 품질, 버그 신고 등 자유롭게 의견을 남겨주세요.

* **참여 방법:** `[소재 상세]` 페이지 진입 → 하단 `[의견 보내기]` 클릭 → 내용 입력 후 전송 📝
* **참여 혜택:** 소중한 의견을 주신 분들 중 추첨을 통해 **런칭 시 사용 가능한 크레딧**을 선물로 드립니다! 💎

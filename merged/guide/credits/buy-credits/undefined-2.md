# 이용권 결제 (백업)

필요한 만큼만 딱! 자유롭게 크레딧을 구매하고 싶다면 이용권을 선택해 보세요.\
1개부터 1만 개까지 우리 팀 상황에 맞춰 구매할 수 있습니다.

### 1️⃣ **이용권 플랜 살펴보기** <a href="#id-1" id="id-1"></a>

리사이즈애드 로그인 후 **\[플랜]** 페이지로 이동해 주세요.\
'이용권' 탭에서 나에게 맞는 플랜 범위를 확인할 수 있습니다.

<figure><img src="../../../.gitbook/assets/image (21).png" alt="" width="563"><figcaption></figcaption></figure>

### 2️⃣ 구매하기 클릭 후 **수량 입력** <a href="#id-2" id="id-2"></a>

구매하고 싶은 크레딧 개수를 입력해 주세요.

<figure><img src="../../../.gitbook/assets/image (22).png" alt="" width="563"><figcaption></figcaption></figure>

{% hint style="info" %}
플랜마다 선택할 수 있는 최소\~최대 수량이 달라요.
{% endhint %}

### 3️⃣ **최종 금액 확인하기** <a href="#id-3" id="id-3"></a>

입력한 수량에 따른 최종 결제 금액을 한 번 더 확인해 주세요. 많이 구매할수록 할인율이 높아집니다.

<figure><img src="../../../.gitbook/assets/image (23).png" alt="" width="563"><figcaption></figcaption></figure>



### 4️⃣ **결제 수단 선택하기** <a href="#id-4" id="id-4"></a>

신용카드, 간편결제, 또는 이미 등록된 카드를 사용할 수 있습니다.

<figure><img src="../../../.gitbook/assets/image (24).png" alt="" width="563"><figcaption></figcaption></figure>

> **💡 카드를 등록해두면 결제가 더 빨라져요!**
>
> * **등록 방법**: \[신용카드] 선택 후 결제창에서 '다음 결제 시 사용할수 있도록 카드 등록'을 체크하고\
>   결제해 주세요.
> * **빠른 결제**: 한 번 등록된 카드는 다음 구매부터 별도 정보 입력 없이 **이메일 인증**만으로 즉시 결제됩니다.
> * 간편결제는 카드 등록 기능을 지원하지 않아요.

### 5️⃣ 결제 완료 <a href="#id-5" id="id-5"></a>

약관 동의 후 **\[결제하기]** 버튼을 눌러주세요. 결제가 완료되면 크레딧이 즉시 지급됩니다.

이제 마음껏 배너 제작을 시작해 보세요! 🪄

<figure><img src="../../../.gitbook/assets/image (25).png" alt="" width="563"><figcaption></figcaption></figure>

* 카드 등록은 몇개까지 가능한가요?
* 카드 등록이 실패했다는 메시지가 떠요.
* 이용권 연장이 가능한가요?
* 이용권에서 구독권으로 바꿀 수 있나요?
* 취소 및 환불 방법이 궁금해요.

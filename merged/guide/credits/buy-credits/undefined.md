# 이용권 결제

필요한 만큼만 딱! \
최소1개부터 최대 1만 개까지 구매할 수 있습니다.

### 1️⃣ **이용권 플랜 살펴보기** <a href="#id-1" id="id-1"></a>

리사이즈애드 로그인 후 **\[플랜]** 페이지로 이동해 주세요.\
나에게 맞는 플랜 범위를 확인할 수 있습니다.

<figure><img src="../../../.gitbook/assets/image (6).png" alt=""><figcaption></figcaption></figure>

### 2️⃣ 구매하기 클릭 후 **수량 입력** <a href="#id-2" id="id-2"></a>

구매하고 싶은 크레딧 개수를 입력해 주세요.

<figure><img src="../../../.gitbook/assets/image (22).png" alt=""><figcaption></figcaption></figure>

### 3️⃣ **최종 금액 확인하기** <a href="#id-3" id="id-3"></a>

입력한 수량에 따른 최종 결제 금액을 한 번 더 확인해 주세요.

<figure><img src="../../../.gitbook/assets/image (23).png" alt=""><figcaption></figcaption></figure>

### 4️⃣ **결제 수단 선택하기** <a href="#id-4" id="id-4"></a>

신용카드, 간편결제를 사용할 수 있습니다.

### 5️⃣ 결제 완료 <a href="#id-5" id="id-5"></a>

약관 동의 후 **\[결제하기]** 버튼을 눌러주세요. 결제가 완료되면 크레딧이 즉시 지급됩니다.

# 비밀번호 재설정/초기화

리사이즈애드 비밀번호는 본인이 직접 변경하거나, 로그인이 어려울 경우\
<mark style="background-color:purple;">**이메일 인증**</mark> 또는 <mark style="background-color:purple;">**대표 사용자의 도움을 통해 초기화**</mark>할 수 있습니다.

#### **1. 비밀번호 재설정 (로그인 중일 때)**

* 로그인 상태에서 보안을 위해 비밀번호를 바꾸고 싶다면 아래 순서대로 진행해 주세요.
  * 내 정보 메뉴에서 `비밀번호 변경하기`를 누릅니다.
  * 현재 사용 중인 비밀번호와 새로 사용할 비밀번호를 입력한 뒤 변경하기를 클릭하면 완료됩니다.

<figure><img src="../../.gitbook/assets/image (32).png" alt="" width="375"><figcaption></figcaption></figure>

#### **2. 비밀번호 초기화 (로그인이 안될 때)**

* 비밀번호가 기억나지 않아 접속할 수 없다면 이메일 인증을 이용해 보세요.
  * 로그인 화면 하단의 `비밀번호를 잊으셨나요?` 링크를 클릭합니다.
  * 가입할 때 사용한 이메일 주소를 입력하면 비밀번호를 다시 설정할 수 있는 링크를 보내드립니다.

#### **3.** 대표 사용자에게 초기화 요청하기

* 직접 초기화하기 어렵다면 팀의 대표 사용자에게 도움을 요청할 수 있습니다.
  * 대표 사용자가 `사용자 계정 관리` 메뉴에서 초기화가 필요한 팀원의 이름을 클릭합니다.
  * 상세 페이지의 `초기화` 버튼을 누르면 해당 팀원의 이메일로 임시 비밀번호가 발송됩니다.
  * 팀원은 발송된 임시 비밀번호로 로그인한 뒤, 안전을 위해 즉시 비밀번호를 변경해 주세요.

<figure><img src="../../.gitbook/assets/image (33).png" alt="" width="375"><figcaption></figcaption></figure>



보안을 위해 비밀번호는 영문 대문자, 특수 문자, 숫자를 포함하여 주기적으로 변경하는 것을 권장합니다.\
상세한 내용은 내 정보 관리 페이지에서 확인하실 수 있습니다.

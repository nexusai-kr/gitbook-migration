### **1. 수많은 광고 규격, 단 하나의 PSD로 자동 완성 🪄**

<mark style="background-color:$primary;">단 한 장의 포토샵 파일(PSD)로 대형 매체부터 버티컬 매체까지</mark> <mark style="background-color:$primary;"></mark><mark style="background-color:$primary;">**약 300여 개 광고 규격**</mark> <mark style="background-color:$primary;"></mark><mark style="background-color:$primary;">대응이 가능합니다.</mark>&#x20;

* 매체별 최신 가이드라인을 토대로 AI가 다양한 시안을 생성합니다.
* 대량의 배너 제작 업무를 단 몇 분 만에 빠르게 생성합니다.

### **2. 어떤 포맷이든 무료 재다운로드 💾**

<mark style="background-color:$primary;">한 번 구매한 소재는 보관함에서</mark> <mark style="background-color:$primary;"></mark><mark style="background-color:$primary;">**90일 동안**</mark> <mark style="background-color:$primary;"></mark><mark style="background-color:$primary;">추가 비용 없이 언제든 다시 확인할 수 있습니다.</mark>

* 파일 분실이나 포맷 변경 걱정 없이 여유로운 업무가 가능해집니다.

<mark style="background-color:$primary;">포토샵이 없어도 괜찮아요. 페이지 내에서 직접 섬세하게 다듬을 수 있습니다.</mark>

* 오브젝트, 텍스트, 로고의 위치와 크기는 물론, 배경 컬러까지 직접 수정해 보세요.

### **4. 매체 가이드 준수 여부 확인 ✅**

<mark style="background-color:$primary;">복잡한 매체별 가이드라인을 AI가 어떻게 반영했는지, 화면에서 바로 확인할 수 있습니다.</mark>

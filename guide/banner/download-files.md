# 완성된 파일 다운로드

구매가 완료된 배너는 파일 보관함에서 간편하게 내려받을 수 있습니다.

### **1️⃣ 제작 완료 알림 확인하기**

* 파일 제작이 완료되면 서비스 내 **상단 알림**과 가입하신 **이메일**로 실시간 알림을 보내드려요.

***

### **2️⃣ 파일 보관함에서 다운로드하기**

* 소재 상세 페이지 우측 상단의 **\[파일 보관함]** 버튼을 클릭하세요.
* 팝업 창에 나타난 리스트에서 내가 생성한 파일명을 확인하고 **\[다운로드]** 버튼을 누르면 압축(ZIP) 파일로 다운로드 됩니다.

<figure><img src="../.gitbook/assets/image (87).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
리스트 상단에 표시된 '다운로드 유효기간' 내에 언제든 다시 받을 수 있습니다.
{% endhint %}

***

### **3️⃣ 다른 포맷이 더 필요할 때**&#x20;

이미 JPG로 받았는데 PSD 파일이 추가로 필요하신가요?

* 처음 구매할 때와 똑같이 소재 상세 페이지에서 해당 이미지를 선택하고,\
  원하는 새로운 포맷(예: PSD)을 골라 \[배너 구매하기]를 다시 눌러주세요.
* **이미 구매한 이력이 있는 배너**라면, 포맷을 다르게 선택해 다운로드 하더라도 **크레딧은 추가로 차감되지 않습니다.**

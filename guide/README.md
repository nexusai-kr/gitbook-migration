# ResizeAd는 어떤 서비스인가요?

원본(PSD) 파일 하나만 업로드하면, 수백 개의 매체별 규격에 맞춘 배너를 몇 분 안에 자동으로 생성합니다.\
단순한 크기 조절이 아닌 AI 레이아웃 재배치 기술을 통해 전문가 수준의 광고 소재를 완성합니다.

***

### 🚀 리사이즈애드, 무엇이 특별한가요?

#### _🎨_ **원본 하나로 수백 개 매체 완벽 대응**

> 원본 키비주얼만 있으면 베리에이션은 문제 없어요.\
> AI가 텍스트·로고 위치까지 분석해 매체별 **최적의 레이아웃**을 자동으로 완성합니다.

#### ✅ **매체 가이드, AI가 알아서 지켜요**

> 네이버 GFA · 구글 GDN · 메타 · 크리테오등 주요 매체의 **최신 가이드라인을 준수하여 생성**합니다.\
> 가이드를 직접 확인하지 않아도 다양한 사이즈의 배너를 순식간에 만들 수 있어요.

#### **🖌️ 내 손으로 직접 편집도 가능해요**

> AI가 만든 배너를 수정하고싶다면? 오브젝트 위치, 크기, 배경 컬러까지\
> **사이트 내에서 자유롭게 편집**하고 완벽한 결과물을 완성해 보세요.

#### ⚡비용은 획기적으로 줄이고, 작업은 단 몇 분만에

> 며칠씩 걸리던 대량 제작, 이제 몇 분이면 충분해요.\
> JPG · PNG는 물론 **PSD 원본**까지 제공해 직접 디테일한 수정도 자유롭게 가능합니다.

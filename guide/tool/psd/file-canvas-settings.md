# 파일 / 캔버스 설정

정확한 규격과 해상도가 고품질 리사이즈 결과물을 만듭니다.

<figure><img src="../../.gitbook/assets/image (59).png" alt=""><figcaption></figcaption></figure>

#### **✅ DO**

* **3종 세트 구성**: 정방형/가로형/세로형총 3개 아트보드를 하나의 PSD에 구성하거나, 비율별로 나뉘어진 PSD를 각각 업로드 해주세요.
* **해상도 준수**: 짧은 변 기준 300px 이상의 캔버스를 사용하세요.
* **1파일 1시안**: 하나의 PSD에는 단 하나의 광고 디자인만 포함해야 합니다.

#### **❌ DON'T**

* **사이즈 초과**: 가로 또는 세로가 2,400px 이상인 이미지는 처리가 불가능합니다.
* **저해상도 주의**: 짧은 변이 300px 이하일 경우 확대 과정에서 화질 저하나 블러 현상이 발생할 수 있습니다.

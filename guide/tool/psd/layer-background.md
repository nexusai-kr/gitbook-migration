# 레이어 / 배경 구성

AI가 요소를 자유롭게 재배치할 수 있도록 모든 구성 요소를 개별 레이어로 분리해 주세요.

#### **✅ DO**

▶ PSD는 모든 구성 요소가 개별적으로 살아있는 상태로 업로드해 주세요.

#### **❌ DON'T**

**▶** 소재 전체를 하나로 합친(Merged) 레이어가 포함되지 않도록 주의하세요.\
베리에이션이 정상적으로 되지 않을 수 있습니다. 개별 레이어가 있더라도 전체를 합친 레이어가\
함께 들어있다면, 해당 레이어는 반드시 삭제 후 업로드해 주세요.
